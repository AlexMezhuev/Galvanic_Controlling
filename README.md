# Galvanic_Controlling
Программа управления обработкой деталей в РТК с использованием методов ситуационного управления.

   Программа состоит из 8 модулей:
     GCRus  --главный модуль,
     GCLoad --модуль начальной загрузки и инициализации состояния объектов,
     GCTime --модуль службы времени,
     GCMenu --модуль меню и пользовательского управления,
     GCState--модуль определения состояний объектов  и  правил работы роботов,
     GCCtrl --модуль управления работой роботов,
     GCTrace--модуль индикации состояния РТК и записи  расписаний движений роботов,
     GCInter--интерфейсный модуль.
